# PlayerOne

An AI playtester. Computer-use agents, running on large cloud models or local Llama models, play your game, find bugs, and write reports. Playtests start automatically through your agent harness.

Built by team Cyber Tesla at NeuroBridge.SI Baku, 9 to 10 October 2026. This repo is the landing site.

## Run it

```bash
npm install
npm run dev      # localhost:5173
npm run build    # dist/
```

React 18, Vite, Tailwind 3, Framer Motion. Space Mono everywhere, Anton SC for the big watermark. The background videos are hosted on CloudFront and only play while they are on screen.
