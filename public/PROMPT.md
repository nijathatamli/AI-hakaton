# PROMPT — public/

Small folder, enormous taste. This is the **#1 project's** asset discipline.

`favicon.svg` — 1KB — is the entire PlayerOne identity: one hand-drawn path, four petals, rotated copies on a black rounded square. The same geometry is reused by `<use>` in the desktop app. One source of truth, zero asset bloat.

And notice what's *not* here: the background videos live on CloudFront and only stream while on screen. The public folder stays tiny on purpose. When your "static assets" directory is this clean, you know the team made deliberate choices instead of dumping files. That's the difference between a project and *the* project.
